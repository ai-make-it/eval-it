Le fondamenta

I termini che servono per leggere tutti gli altri.

10 voci. Torna a tutte le voci.

  • Token token

    L'unità in cui un modello spezza il testo prima di elaborarlo.

  • Finestra di contesto context window

    Quanto testo il modello riesce a tenere davanti agli occhi in una volta sola.

  • Temperatura temperature

    Il parametro che decide quanto il modello si allontana dalla scelta più probabile a ogni passo.

  • Allucinazione hallucination

    Quando il modello produce un'affermazione falsa con la stessa sicurezza con cui ne produce una vera.

  • Valutazione eval, evaluation

    Il processo con cui si misura se un sistema fa quello che deve, su un insieme di casi scelti apposta e sempre gli...

  • Ground truth ground truth

    La risposta corretta contro cui si confronta l'output del sistema.

  • Benchmark benchmark

    Un insieme standard di prove usato per confrontare modelli diversi sulla stessa base.

  • Drift drift, model drift, data drift

    Il peggioramento graduale di un sistema che nessuno ha toccato, perché è cambiato il mondo intorno.

  • Regressione regression

    Quando una modifica migliora una cosa e ne peggiora un'altra senza che nessuno se ne accorga.

  • Prompt injection prompt injection

    Quando un'istruzione nascosta dentro il materiale che il sistema legge, una pagina web, un documento, una mail, viene...
