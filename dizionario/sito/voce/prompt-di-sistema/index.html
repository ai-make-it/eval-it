Come si usa

Prompt di sistema

In inglese: system prompt

Cos'è

Le istruzioni permanenti che stanno sopra ogni conversazione e definiscono ruolo, vincoli e comportamento del sistema. L'utente di solito non le vede.

Perché conta

È il posto dove si mettono le regole che non devono cambiare, ed è anche il posto dove finisce, negli anni, tutta la complessità accumulata di un sistema. Un prompt di sistema che nessuno rilegge da sei mesi è un debito.

L'errore comune

Considerarlo una protezione. Non è un confine di sicurezza: contenuto ostile nel resto del contesto può contraddirlo.
