Le fondamenta

Prompt injection

In inglese: prompt injection

Cos'è

Quando un'istruzione nascosta dentro il materiale che il sistema legge, una pagina web, un documento, una mail, viene eseguita come se fosse un comando dell'utente.

Perché conta

È il problema di sicurezza strutturale di qualunque sistema che legga contenuto esterno o usi strumenti per conto di qualcuno, e a oggi non ha una soluzione completa. Si mitiga, non si chiude.

L'errore comune

Confonderla con il jailbreak. Nel jailbreak è l'utente che prova ad aggirare le regole. Nella prompt injection l'utente è la vittima.
