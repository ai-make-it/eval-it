Come si usa

Output strutturato

In inglese: structured output

Cos'è

Vincolare la risposta a una forma prestabilita, tipicamente uno schema JSON, invece di lasciarla in testo libero.

Perché conta

È quello che rende un modello utilizzabile dentro un software invece che solo davanti a una persona. Elimina un'intera classe di errori di interpretazione a valle.

L'errore comune

Credere che un output valido sia un output corretto. Lo schema garantisce la forma, non il contenuto: un JSON perfettamente formato può contenere un dato inventato.
