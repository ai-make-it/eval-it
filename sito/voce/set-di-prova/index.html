Come si verifica

Set di prova

In inglese: test set, eval set

Cos'è

L'insieme dei casi su cui si misura il sistema, fissato in anticipo e usato sempre uguale a ogni misurazione.

Perché conta

Se cambia a ogni giro, i risultati non sono confrontabili nel tempo e non si può sapere se una modifica ha migliorato o peggiorato le cose.

L'errore comune

Costruirlo con i casi facili, quelli che si avevano sottomano. Un set di prova senza casi difficili produce risultati eccellenti e nessuna informazione utile.
